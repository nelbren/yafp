# OSC 133 configuration

## Windows (PowerShell)

1. Open Windows Terminal, press `Ctrl+,`, and select **Open JSON file**.

2. In the existing `"profiles"` object, add or merge the following settings
   under `"defaults"`:

   ```jsonc
   "profiles": {
       "defaults": {
           // OSC 133
           "rightClickContextMenu": true,
           "showMarksOnScrollbar": true,
           "useAcrylic": true
       }
   }
   ```

   Do not create a second `"profiles"` object if one already exists.

3. Add the following entries to the existing top-level `"actions"` array:

   ```jsonc
   "actions": [
       {
           // OSC 133
           "command": {
               "action": "scrollToMark",
               "direction": "next"
           },
           "id": "User.scrollToMark.2A0DA8E0"
       },
       {
           "command": {
               "action": "scrollToMark",
               "direction": "previous"
           },
           "id": "User.scrollToMark.D3F0B923"
       }
   ]
   ```

4. Bind the action identifiers to the Windows Terminal shortcuts:

   | Shortcut | Action |
   | --- | --- |
   | `Alt+Up` | Scroll to the previous OSC 133 mark. |
   | `Alt+Down` | Scroll to the next OSC 133 mark. |

   Add these entries to the existing top-level `"keybindings"` array:

   ```jsonc
   "keybindings": [
       {
           "keys": "alt+up",
           "id": "User.scrollToMark.D3F0B923"
       },
       {
           "keys": "alt+down",
           "id": "User.scrollToMark.2A0DA8E0"
       }
   ]
   ```

5. Enable OSC 133 in `yafp-cfg.ps1`:

   ```powershell
   $global:YAFP_OSC133 = 1
   ```

6. Reload YAFP or open a new PowerShell session. Run several commands and use
   the scrollbar marks or the configured actions to move between prompts.

Windows Terminal supports the OSC 133 sequences used to identify prompts,
commands, output, and exit status. Marks are stable starting with Windows
Terminal 1.21. See Microsoft's
[Windows Terminal Shell Integration documentation](https://learn.microsoft.com/en-us/windows/terminal/tutorials/shell-integration).

## Unix (Bash)

1. Enable OSC 133 in `yafp-cfg.bash`:

   ```bash
   YAFP_OSC133=1
   ```

2. Reload YAFP or open a new Bash session:

   ```bash
   source /path/to/yafp/yafp-ps1.bash
   ```

3. Run several commands in a terminal that supports OSC 133. The terminal can
   then identify prompts, commands, command output, and command completion.

4. iTerm2 already provides keyboard shortcuts for navigating OSC 133 marks, so
   you do not need to create equivalent actions:

   | Shortcut | Action |
   | --- | --- |
   | `Cmd+Shift+Up` | Go to the previous OSC 133 mark. |
   | `Cmd+Shift+Down` | Go to the next OSC 133 mark. |

   The same commands are available under **Edit → Marks and Annotations →
   Previous/Next Mark**. See the
   [iTerm2 Shell Integration documentation](https://iterm2.com/3.5/documentation-shell-integration.html).
